# Toxic Comment Detection System

An end-to-end NLP and Machine Learning application that classifies comments as **Clean, Mildly Toxic, or Highly Toxic**.

* Built with **Python, NLP, CountVectorizer, Machine Learning, Streamlit, and SQL**.
* Applies text preprocessing including lowercasing, noise removal, and normalization.
* Converts comments into numerical features using **CountVectorizer**.
* Provides an interactive Streamlit UI for submitting, viewing, and searching comments.
* Stores comments and prediction results in a SQL database.
* Demonstrates an end-to-end workflow from **text preprocessing → ML prediction → database storage → interactive UI**.
